---
name: announce-stage
description: Explain the purpose and observable effect of a demonstration stage before acting.
---

Print `[DEMO ENTER]` before the action. Name the stage, purpose, primitive, expected input, and requested output. After acting, print `[DEMO OBSERVATION]` with the actual input read, action taken, output written, and concrete effect. Finish with `[DEMO EXIT]` naming the accepted result and next stage. Use facts, not generic claims.
